# LSE vocales

Práctica de las vocales (A, E, I, O, U) del alfabeto dactilológico de la Lengua de Signos Española con la cámara del portátil (MediaPipe Hand Landmarker). Valida la postura de la mano derecha.

Dibujos del alfabeto: © María Nicolás Abellán ([HistoriasDiversas.com](https://historiasdiversas.com), @marianiabe), licencia CC BY-NC-SA. Recortadas las cinco vocales del cartel original. Uso educativo no comercial.
